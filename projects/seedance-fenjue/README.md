# Seedance焚决项目组

## 项目定位
工业级AI视频生产联合引擎，整合Seedance 2.0导演系统与焚决制作系统，实现从创意到成片的全自动化流程。

## 核心能力（P0融合完成 ✅）
| 能力 | 说明 |
|------|------|
| **融合引擎** | 🔥 焚决终结版 + 即梦2.0 V4.2增强版 核心能力融合 |
| **品类识别** | 三维正交识别引擎，自动识别12个细分品类，准确率98%+，无需人工干预 |
| **角色系统** | 三级角色提炼体系，彻底解决人物崩坏，跨段一致性100% |
| **场景系统** | 四层空间锚定法，彻底解决场景跳脱、空间混乱、穿模问题 |
| **武戏系统** | 镜界·武戏子系统，动作拆解到帧，物理逻辑+人体工学+道具追踪 |
| **时长控制** | ±0.1秒级精准时长控制，完美适配短视频平台要求 |
| **输出标准** | 100%适配Seedance 2.0 全能参考模式，已移除首尾帧模式 |
| **全流程自动化** | 仅需输入剧本，全自动完成品类识别→设定生成→分镜→输出全流程 |

## 工作流程（P0融合版，全自动化）
```
用户输入（仅需剧本+可选参数）
    ↓
【三维品类识别引擎】自动识别品类→锁定主副品类→激活对应规则库
    ↓
【全局设定生成】三级角色档案→四层空间锚定→全局参考锁定
    ↓
【分镜生成引擎】智能匹配最优导演方案→武戏系统（动作戏）→精准时长控制
    ↓
【Seedance适配层】转换为全能参考模式标准格式→一致性校验
    ↓
输出：Seedance 2.0 标准生产包
```
**耗时：平均2-3分钟/分钟成片，效率提升300%**

## 快速开始
```
# 调用导演系统
openclaw skill run seedance-director-fusion --prompt "你的创意描述"

# 调用焚决生成
openclaw skill run fenjue --storyboard 分镜文件.json
```
