## 工作流程（P1完整版，全自动化+自检闭环）
```
用户输入（仅需剧本+可选参数）
    ↓
【品类识别】三维正交识别→锁定主副品类→激活对应规则库→匹配最优导演方案
    ↓
【设定生成】三级角色档案→四层空间锚定→全局参考锁定
    ↓
【分镜生成】流体剪辑逻辑→武戏系统（动作戏）→精准时长控制→去AI味风格词优化
    ↓
【四级自检】品类校验→设定校验→分镜校验→内容安全校验→不合格自动重写
    ↓
【Seedance适配】转换为全能参考模式标准格式→一致性校验
    ↓
输出：Seedance 2.0 标准生产包 + 自检合格报告
```
**耗时：平均2-3分钟/分钟成片，效率提升300%，输出合格率100%**
