# 三级角色设定体系规则
## 三级提炼标准
### 第一级：完整角色档案（约2000字，参考用）
包含五个部分：
1. 基础外形全描述（约500字）：面部骨骼结构、五官精确比例、肤色色号、发型层次、妆容细节
2. 服装分层全描述（约500字）：内搭、中衣、外装、配饰、鞋靴，每层标注材质/颜色/版型/标识
3. 武器道具全描述（约300字）：尺寸、材质、外观、特效属性、携带方式
4. 气质动态全描述（约400字）：站姿、行走、战斗、情绪变化时的肢体语言特征、标志性微表情
5. 变化规则（约300字）：不同剧情阶段外形变化对照表，触发条件和视觉差异

### 第二级：核心锚定词（约200字，全段重复锁定）
提炼公式：
```
{性别}+{年龄段}，{最突出面部特征2个}，{发型核心描述}，{服装最具识别度特征1个}，{服装主色调}，{标志性配饰/武器1个}，{体型}，{气质关键词2个}
```
示例：
```
18岁少年，剑眉星目、瞳色琥珀偏金，黑发束高马尾以白玉冠固定，身着月白色交领长袍外罩淡青纱质外衫，腰系墨蓝织金腰带，左腰悬挂古铜色剑鞘长剑剑柄缠白色丝绦，身形清瘦挺拔，气质清冷疏离、少年意气未消
```
👉 **强制要求：每段脚本开头必须重复完整核心锚定词，一字不改**

### 第三级：生成种子词（约50字，提示词前缀）
提炼公式：
```
{gender} {age}, {hair style} {hair color}, {clothing color} {clothing style}, {strongest identifying feature}
```
示例：
```
18-year-old young man, black hair in high ponytail with white jade crown, white and light blue Chinese traditional robe, amber golden eyes
```
👉 **强制要求：每段Seedance提示词前缀必须包含完整种子词，一字不改**

## 跨段一致性保障
1. 所有段落核心锚定词完全一致，不得新增/修改/省略任何视觉特征
2. 所有段落种子词完全一致
3. 优先使用第1段生成的角色图作为后续所有段的参考图
4. 配角/反派设定同主角标准，全片固化
