# 四层空间锚定规则
## 第一层：场景整体定性
场景唯一代号：每个场景分配唯一代号（如「场景A：竹林对决」），全片统一调用。
空间定性格式：`{空间定性} + {空间类型} + {纵深感} + {核心氛围}`
空间类型可选值（禁止自造）：
- 开阔空旷：荒野/战场/沙漠 → vast open landscape wide horizon
- 纵深幽长：长廊/古巷/山谷 → deep narrow corridor vanishing point perspective
- 封闭逼仄：密室/牢房/小屋 → cramped interior low ceiling tight space
- 半开半闭：客栈/宫殿/军帐 → semi-enclosed space one side open to exterior
- 垂直纵深：悬崖/高塔/深渊 → extreme vertical depth looking down or up
- 层次纵深：竹林/树林/宫殿群 → layered depth with foreground midground background elements

## 第二层：画面分区锚定（黄金构图栅格法）
竖屏9:16画面划分为9个区域：
```
左上LT | 中上CT | 右上RT
左中LM | 正中CM | 右中RM
左下LB | 中下CB | 右下RB
```
描述格式：`{人物/道具名称} + {画面分区位置} + {景深层次} + {占画面比例} + {朝向}`
景深层次仅分3级：
- 前景层（foreground）：离镜头最近，可虚化/遮挡
- 主体层（mid-ground in focus）：画面焦点，清晰锐利
- 背景层（background soft focus）：最远处，虚化/环境交代

## 第三层：人物空间关系锚定（相对关系法）
6种基本关系：
1. 对峙关系：A与B面对面相距若干身位 → 打斗/谈判/对话
2. 并肩关系：A与B并肩站立/行走间距若干肩宽 → 同行/结盟/共同面对
3. 前后关系：A在前B在A身后若干步远 → 追逐/保护/跟随
4. 高低关系：A站在高处俯视下方的B → 权力压制/居高临下
5. 包围关系：A被B1/B2/B3从三面包围仅某方向有退路 → 围攻/困境
6. 背对关系：A与B背对背各自面向某方向 → 信任/决裂/分道扬镳

距离描述标准（禁用米/厘米，统一用画面相对值）：
- 贴身：两人几乎接触 → 双人同框特写
- 一臂距离：伸手可触及 → 双人近景
- 三步之遥：正常交谈距离 → 双人中景
- 隔开一段距离：需要大声说话 → 双人中远景
- 画面两端：画面左右极限 → 广角对峙构图

## 第四层：轴线与运动方向锚定
1. 对话对峙双人戏：全程锁定一侧拍摄，如「镜头始终从右侧拍摄两人对话，A始终在画面左侧，B始终在画面右侧，全场不切换方向」
2. 越肩镜头：如「从A的右肩后方拍向B，A的肩膀和后脑勺占据画面左侧前景虚化，B在画面右侧中景清晰，B的面部表情为焦点」
3. 人物运动方向：全场统一，如「主角全场从画面左侧向右侧移动，反派全场从画面右侧向左侧移动，两人相向而行直到交汇」

## 场景复用规则
同一场景多次出现时，空间定性、画面分区、人物关系、轴线方向完全一致，无逻辑偏差。
