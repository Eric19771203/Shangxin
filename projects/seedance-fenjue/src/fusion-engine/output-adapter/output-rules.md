# Seedance 2.0 输出适配规则
## 唯一输出标准：全能参考模式（已移除首尾帧模式）
### 全局参考锁定（强制）
每个模块提示词前缀必须包含：
```
@全局角色参考 @全局场景参考 @全局风格参考
```
参考权重固定为0.9，最大程度保持全片一致性。
### 提示词结构（强制标准）
```
[第三级角色生成种子词]
[第二级角色核心锚定词]
[场景锚定描述]
[镜头+动作+画面描述]
[风格+光影+质感关键词]
[负面提示词]
```
### 负面提示词标准（强制）
```
畸形、模糊、低质量、多余肢体、画面崩坏、人物形象变动、穿模、跳帧、光影跳变、场景跳变
```
### 生产参数（强制）
| 参数 | 固定值 |
|------|--------|
| 模型 | Seedance 2.0 全能版 |
| 分辨率 | 1080p |
| 帧率 | 24fps |
| 参考模式 | 全局锁定 |
| 参考权重 | 0.9 |
| 首尾帧模式 | ❌ 禁用 |
### 输出结构标准
```
# Seedance焚决融合引擎 生产包
## 1. 基础信息
- 项目名称：XXX
- 品类识别：W{X}+D{X}+F{X} → 主品类：XXX，副品类：XXX
- 总时长：{N}秒（{M}个15秒模块）
## 2. 全局设定
### 角色锚定
{第二级核心锚定词全文}
### 场景锚定
{场景整体定性+空间描述}
### 风格参考
{导演风格+色彩基调+光影描述}
## 3. 分镜提示词（每个模块）
### Module {N}（{XX}-{XX}秒）
```
@全局角色参考 @全局场景参考 @全局风格参考
[提示词全文]
```
## 4. 生产参数
- 分辨率：1080p
- 帧率：24fps
- 参考权重：0.9
- 适配：Seedance 2.0 全能参考模式
```
## 一致性校验规则
输出前必须自检：
1. 所有模块提示词前缀包含完整全局参考标记
2. 所有模块角色锚定词完全一致
3. 所有模块场景描述逻辑一致
4. 无任何首尾帧相关描述
5. 完全符合Seedance2.0官方生成规则
