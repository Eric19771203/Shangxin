# 去AI味风格词库
## 核心理念
替换AI流水线式通用描述，使用专业电影工业级词汇，让画面更具质感、真实感、电影感。
## 分类词库
### 光影类（替代"明亮""黑暗"等通用词）
| AI通用词 | 专业替代词 | 效果 |
|----------|------------|------|
| 明亮 | 黄金时刻侧逆光/柔光箱轮廓光/窗格投影天光/正午顶光 | 光影有来源、有质感、有温度 |
| 黑暗 | 低光暗调+体积光/鬼火蓝冷光/火把暖橙色摇曳光/月光硬阴影 | 有层次、有氛围、有情绪 |
| 清晰 | 8K超高清/ARRI Alexa色彩科学/胶片颗粒感/库克镜头畸变 | 有电影质感、有设备属性 |
| 模糊 | 浅景深虚化/运动动态模糊/烟雾弥散模糊/焦外散景 | 有原因、有风格、有层次 |

## 强制应用规则
1. 所有提示词中禁止使用AI通用模糊描述词，必须使用专业级词汇
2. 每个提示词必须包含至少3个专业风格/光影/质感/运镜关键词
3. 风格关键词需与对应品类匹配，不得跨品类混用
4. 最终提示词长度控制在150-300字之间，简洁精准
## 示例对比
❌ AI味版本：
```
明亮的房间里，一个好看的男人站在那里，真实的皮肤，衣服很好看，画面很清晰
```
✅ 去AI味版本：
```
黄金时刻侧逆光透过窗格在墙面投下条纹光影，30岁男性站在画面正中三分法位置，皮肤有细微汗渍毛孔细节，身穿深灰色亚麻西装面料纹理清晰，ARRI Alexa色彩科学，8K超高清，浅景深虚化背景
```
