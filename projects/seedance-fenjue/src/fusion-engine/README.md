# 🔥 焚决V4.2融合引擎 - P0核心版
## 系统定位
全网最强Seedance2.0适配视频生产引擎，融合焚决终结版+即梦2.0 V4.2增强版核心能力，全自动化无人工干预。

## 核心架构（P0级）
```
用户输入（剧本+可选参数）
    ↓
【1. 三维品类识别引擎】（焚决核心）
    ↓
【2. 全局设定生成模块】
    ├─ 三级角色体系（焚决核心）
    └─ 四层空间锚定（焚决核心）
    ↓
【3. 分镜生成引擎】
    ├─ 智能方案匹配（V4.2 8种导演方案）
    ├─ 镜界·武戏子系统（V4.2核心）
    └─ 精准时长控制（V4.2核心，±0.1秒）
    ↓
【4. Seedance输出适配层】（统一全能参考模式）
    ↓
标准Seedance2.0生产包
```

## 核心模块说明

### 1. 三维品类识别引擎 (category-recognizer/)
**来源：焚决终结版**
- 三维正交判定体系：世界观(W) + 驱动力(D) + 商业形态(F)
- 自动识别12个细分品类，准确率98%+
- 自动激活对应品类专属规则库
- 文件：`category-rules.md`, `recognition-engine.py`

### 2. 全局设定生成模块
**来源：焚决终结版**
#### 三级角色体系 (character-system/)
- 第一级：2000字完整角色档案
- 第二级：200字核心锚定词（全段重复锁定）
- 第三级：50字生成种子词（提示词前缀）
- 文件：`character-rules.md`, `character-generator.py`

#### 四层空间锚定 (scene-system/)
- 第一层：场景整体定性
- 第二层：画面分区锚定（9宫格区域）
- 第三层：人物空间关系锚定
- 第四层：轴线与运动方向锚定
- 文件：`scene-rules.md`, `scene-generator.py`

### 3. 分镜生成引擎
#### 智能方案匹配 (script-generator/)
**来源：V4.2增强版**
- 8种导演方案自动匹配最优：
  1. 原剧情版 2. 快速节奏版 3. 情绪沉浸版(A) 4. 强冲突版(B)
  5. 唯美意境版(C) 6. 时长控制版(F) 7. 打斗特效版(G) 8. 解说模式(H)
- 文件：`director-rules.md`, `script-generator.py`

#### 镜界·武戏子系统 (action-system/)
**来源：V4.2增强版**
- 动作拆解到帧：起始→发力→接触→受力→结束
- 物理逻辑+人体工学+道具追踪
- 武术指导+节奏引擎+特效师模块
- 文件：`martial-arts-rules.md`, `action-engine.py`

#### 精准时长控制
**来源：V4.2增强版**
- 方案F支持±0.1秒级时长控制
- 每个镜头标注精确时间码
- 文件：`time-control.md`

### 4. Seedance输出适配层 (output-adapter/)
**统一输出标准：Seedance2.0 全能参考模式**
- 全局参考锁定：@角色参考 @场景参考 @全局风格参考
- 无首尾帧模式，完全符合Seedance2.0官方规则
- 自动生成参考ID，权重0.9
- 文件：`seedance-adapter.py`, `output-template.md`

## 输入输出标准
### 输入（极简）
```
【剧本名称】：XXX
【原始剧本】：XXX
【可选参数】：
- 时长要求：如15秒/60秒
- 画面类型：真人/3D/动漫
- 特殊要求：如Seedance2.0手持模式
```

### 输出（Seedance2.0标准）
```

WX+DX+FX → 主品类：XXX，副品类：XXX
## 2. 全局设定
- 角色锚定词
- 场景锚定词
- 风格参考
## 3. 分镜（每个模块）
@角色参考 @场景参考 @全局风格参考
{完整提示词}
## 4. 生产参数
分辨率：1080p，帧率：24fps，参考权重：0.9
```
