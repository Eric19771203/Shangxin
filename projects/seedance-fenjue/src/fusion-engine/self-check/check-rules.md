# 全流程自检闭环规则
## 三级自检机制，不合格自动重写，输出合格率100%
---
### 第一级：品类校验（生成前）
- **校验内容**：
  1. 三维品类识别结果是否正确，是否符合剧本内容
  2. 激活的规则库是否与主副品类匹配
  3. 导演方案是否符合场景要求
- **不通过处理**：重新识别品类，调整规则库
---
### 第二级：设定校验（生成中）
- **校验内容**：
  1. 角色锚定词是否符合三级提炼标准，有无遗漏关键特征
  2. 场景锚定是否符合四层空间锚定规则，空间逻辑是否自洽
  3. 全局参考ID是否正确生成，所有模块是否统一
- **不通过处理**：重新生成全局设定，修正错误
---
### 第三级：分镜校验（生成后）
- **校验内容**：
  1. 剧本覆盖度检查：每一句原文都被至少一个镜头覆盖，对话100%对应
  2. 一致性检查：所有模块角色/场景/风格描述完全一致，无矛盾
  3. 逻辑检查：剧情连贯，动作合理，无穿模/空间跳脱/人设崩坏
  4. Seedance格式检查：是否符合全能参考模式标准，无首尾帧相关内容
  5. 时长校验：总时长误差≤±0.1秒（方案F）
---
### 第四级：内容安全校验（输出前）
- **敏感词检测引擎**：
  1. 政治敏感词检测
  2. 色情低俗内容检测
  3. 暴力恐怖内容检测
  4. 其他违规内容检测
- **处理规则**：检测到敏感内容自动替换/删除，严重问题提示用户
---
## 自检报告输出
所有校验通过后，在生产包末尾附自检报告：
```
## 自检报告
✅ 品类识别正确：WX+DX+FX → XXX
✅ 角色设定合规：三级锚定完整
✅ 场景设定合规：四层锚定逻辑自洽
✅ 分镜覆盖率：100%（共N句原文，覆盖N句）
✅ 一致性校验通过：所有模块设定统一
✅ Seedance格式合规：全能参考模式，无首尾帧
✅ 内容安全检测通过：无违规内容
```
## 错误处理机制
1. 单个模块校验不通过：自动重写该模块
2. 全局设定校验不通过：重新生成全部设定
3. 内容安全检测不通过：提示用户修改剧本或自动调整
4. 连续3次校验不通过：终止生成并提示问题原因
