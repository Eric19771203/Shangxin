# 镜界·武戏子系统规则
## 适用场景
- 动作密集场景：高燃打斗/写实格斗/武侠对决/仙侠斗法
- 自动激活条件：品类识别为D1动作对抗驱动，或用户明确指定「打斗戏」
## 动作拆解标准（强制5步分解）
每个完整动作必须拆解为：
```
1. 起始：动作准备姿态，肌肉绷紧/武器蓄力/重心移动
2. 发力：力量爆发瞬间，肢体/武器运动轨迹启动
3. 接触：双方/人与道具碰撞瞬间，受力形变/特效爆发
4. 受力：受力方反应，身体位移/表情变化/物体破坏
5. 结束：动作收尾姿态，回归平衡/下一个动作起势
```
## 强制规则
### 物理逻辑规则
1. 人体工学合规：动作符合人体运动规律，无反关节/反物理运动
2. 道具追踪：武器/道具全程跟随人物动作，无穿模/脱手/瞬移
3. 环境互动：打斗对环境产生对应破坏（碎石/火花/冲击波/气流）
4. 重量感体现：不同重量武器/人物动作节奏符合重量逻辑
### 节奏引擎规则
1. 快慢结合：快动作（1-2帧）+ 慢动作（关键打击帧）交替
2. 呼吸感：每个完整动作循环包含「蓄力→爆发→停顿」节奏
3. 打击密度：每秒2-3个有效打击点，避免连续快剪导致视觉疲劳
### 导演模块规则
1. 镜头语言：打斗场景优先使用：
   - 手持跟拍：增强临场感
   - 低角度仰拍：增强力量感
   - 快速推拉：强化冲击感
   - 特写镜头：关键打击/表情/武器细节
2. 动作剪辑：动势剪辑，前一个动作的尾帧与下一个动作的首帧动势方向一致
3. 特效同步：所有特效必须与动作峰值帧完全同步
## 时长控制（方案F专属）
- 每个动作标注精确时间码，总时长误差±0.1秒
- 关键打击帧必须落在黄金时间点（如第3秒/第7秒/第12秒）
## 输出格式适配
武戏场景Seedance提示词强制包含：
```
动作丝滑流畅，物理逻辑真实，打击感强烈，镜头晃动自然，无穿模，无人物崩坏
```
