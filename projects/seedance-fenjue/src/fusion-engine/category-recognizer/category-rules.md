# 三维品类识别引擎规则
## 三维正交判定体系
### 维度1：题材世界观 (W) - 8选1，按决策树顺序判定
1. W8 现实商业世界：剧本服务于真实商业品牌/产品推广
2. W6 跨时空多世界观：主线涉及两个及以上世界观切换且穿越是核心剧情
3. W3 真实历史世界：包含可考证真实历史人物/朝代/事件且无虚构超自然元素
4. W1 东方仙侠世界：存在修炼境界体系/灵气/法宝等仙侠力量体系
5. W2 东方武侠世界：以武功招式+江湖门派+侠义叙事为核心，无仙侠元素
6. W4 东方暗黑民俗世界：核心为东方民俗恐怖/诡谲/暗黑氛围营造
7. W5 现代近未来世界：主时间线在现代或近未来
8. W7 原创架空世界：以上都不满足

### 维度2：核心叙事驱动力 (D) - 6选1，按决策树顺序判定
1. D5 氛围意境驱动：无明确冲突主线，靠画面意境吸引
2. D1 动作对抗驱动：打斗/追逐/战斗场面占比≥50%
3. D3 对话交锋驱动：对话/独白占比≥70%
4. D4 情绪变身驱动：核心看点为人物情绪递进到爆发/觉醒/变身过程
5. D2 情感关系驱动：主线为人物间情感关系发展/转折
6. D6 叙事传记驱动：以上都不满足

### 维度3：商业形态 (F) - 4选1
1. F1 短视频短剧单集：单集≤3分钟，面向短视频平台
2. F2 中长视频微电影：单集3-30分钟，面向长视频平台
3. F3 概念片氛围片：无商业转化目的，纯视觉/概念表达
4. F4 商业广告品牌片：服务于品牌产品商业转化

1. 用户强制指定品类优先
2. W8商业世界直接锁定品类12
3. W6跨时空直接锁定品类6
4. W3历史世界锁定品类8
5. W4暗黑+D5氛围锁定品类9
6. 双命中时驱动力决定主品类，世界观决定副品类
