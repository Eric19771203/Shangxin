## 分段规则

- 当原文总字符数（含标点、空格）超过10000字时，自动分段处理。
- 分段方法：按5000字左右一段，优先在换行符处分割，其次在句号、感叹号、问号后分割，再次在逗号或空格后分割，确保不切断词语。
- 每段开头添加标记【分段X】（X为数字），原文内容保持不变。

## 替换规则

1. **敏感词与画面违规词汇处理**：
   - 遍历敏感词库（包括原列表及画面违规词汇扩展库中的词汇），若原文中包含该词（全字匹配，英文忽略大小写），则进行替换。
   - 优先使用“画面违规词汇对照表”中给出的推荐替换词汇，但需根据上下文微调，确保语义自然。
   - 对于不在对照表中的词汇，AI应根据该词所在句子的上下文，生成一个语义相近且不敏感的合规表达。替换应保持原句流畅、意思不变。
   - 例如：“她穿着性感的礼服出场” → “她穿着迷人的礼服出场”
   - “画面中出现大量血腥镜头” → “画面中出现大量激烈冲突镜头”
   - 如果无法生成合适替换，可采用通用模糊词（如“手机号码”统一为“联系方式”），但优先使用AI动态生成。
2. **不规则符号处理**：遍历不规则符号列表，若符号出现，则根据上下文替换为合适的中文词语或标点。默认映射如下（AI可酌情调整）：
   - `=` → 替换为“等于” 或 根据语境省略
   - `|` → 替换为“或” 或 “、”
   - `#` → 替换为“井号” 或 删除（如无意义）
   - `￥` → 替换为“人民币” 或 “元”
   - `%` → 替换为“百分之”
   - `@` → 替换为“at” 或 “在”
   - `+` → 替换为“加” 或 “和”
   - `——` → 替换为“破折号” 或 保留为中文破折号（若上下文允许）
   - `《》『』` → 这些是中文标点，通常可保留；但若出现在不适宜位置，可替换为双引号或删除（由AI判断）
3. **去重**：同一位置若命中多个规则，按敏感词优先处理，或合并生成合理替换。

## 注意事项

- 替换时需保持原文本的段落结构和标点基本完整，避免过度修改。
- 若遇到无法处理的复杂情况（如敏感词组合、歧义），可适当保留原文并添加注释（但注释不应出现在最终输出中），或者采用最安全的模糊替换。
- 最终输出应是一个可直接使用的剧本/小说文本，无需用户进一步操作。
- 画面违规判断应结合上下文：有些词汇在特定语境下可能不违规（如医学描述中的“鲜血”），AI需审慎判断是否替换。
