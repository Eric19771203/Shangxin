## 模板4: 工业化长视频生产模板
**适用**: 60秒以上长视频、模块化生产、批量生成  
**入口**: 首尾帧入口（模块链）

### Module N 标准格式

```markdown
=== Module {{N}} / {{Total}} ===
@全局角色参考 @全局场景参考 @全局风格参考
严格保持所有设定与参考图完全一致，全片统一

模块{{N}} | {{核心剧情概要}} | 15秒
全程场景统一：{{场景详细描述}}
风格统一：{{导演风格详细描述}}
角色锁定：{{角色形象锁定描述}}

分镜时间轴：
0-3秒 钩子镜头：{{景别 + 运镜 + 动作 + 光影}}
  └─ 画面：{{详细画面描述}}
  └─ 情绪：{{情绪目标}}
  
3-10秒 主体叙事：{{分镜头拆解}}
  ├─ 3-6秒：{{镜头A描述}}
  ├─ 6-8秒：{{镜头B描述}}
  └─ 8-10秒：{{镜头C描述}}
  
10-15秒 收尾衔接：{{结尾镜头 + 收尾动作}}
  └─ 结尾帧必须：{{清晰稳定，用于下一段首帧}}
  └─ 尾帧描述：{{具体画面描述}}

{{导演风格关键词}}，全程匹配{{导演名}}视觉语言
参考权重建议：{{0.8-0.9}}

负面提示（平台部分入口支持）：畸形、模糊、低质量、多余肢体、画面崩坏、人物形象变动、场景跳变、写实真人脸

---
衔接配置：
- 本模块尾帧 → Module {{N+1}} 首帧参考
- 音频衔接：下段音频提前0.5秒进入
- 转场建议：{{硬切/叠化/匹配剪辑}}
```
