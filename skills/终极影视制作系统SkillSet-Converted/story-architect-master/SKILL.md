# SKILL: 故事架构大师 (Story Architect Master)

## 元数据
- **ID**: ultimate-story-01
- **名称**: 故事架构大师
- **类型**: file
- **分类**: 故事创作
- **标签**: ["故事", "架构", "剧本", "创作", "五阶段", "叙事工程"]

## 描述
集严谨逻辑与狂野想象于一身的"创世架构师"系统。将用户的微小灵感通过多维度推演，构建成具有商业潜力、文学深度且逻辑闭环的**故事圣经（Story Bible）**。

## 核心功能
1. **种子破壳与概念升维** - 类型定位、主题论辩、高概念Logline
2. **角色弧光与心理侧写** - 主角/反派/关键关系三维构建
3. **精细化情节节拍** - 15个关键节拍完整蓝图
4. **世界构建与感官沉浸** - 物理规则、美学氛围、感官锚点
5. **逻辑审查与修辞润色** - 漏洞扫描、开篇打磨

## 五阶段深度创作工序

### 第一阶段：种子破壳与概念升维（Deep Concepting）
1. **类型定位与混合** - 确定主类型+副类型
2. **主题论辩** - 格式："[主题A]与[主题B]的对抗"
3. **高概念Logline** - [有缺陷的主角] + [激励事件] + [必须完成的目标] + [对抗强大的阻力] + [失败的代价]

### 第二阶段：角色弧光与心理侧写（Character Dynamics）
**主角（Hero）**：
- **面具（Persona）** - 外在表现出的性格
- **幽灵（The Ghost）** - 过去的创伤性事件
- **谎言（The Lie）** - 深信不疑的错误人生信条
- **真实需求（The Need）** - 必须学会的真理

**反派（Shadow）**：
- 与主角互为镜像，"自己故事里的英雄"

**关键关系（B-Story）**：
- 承载情感核心，推动主角从"谎言"走向"真实"

### 第三阶段：精细化情节节拍（Beat Sheet Construction）

**第一幕：现状与打破**
- 现状（Set-up）+ 救猫咪时刻
- 催化剂（Catalyst）
- 争辩（Debate）
- 第二幕衔接点（Break into Two）

**第二幕：试炼与质变**
- 游戏时间（Fun and Games）
- 中点（Midpoint）- 伪胜利/伪失败
- 一无所有时刻（All is Lost）
- 灵魂黑夜（Dark Night of the Soul）

**第三幕：综合与解决**
- 高潮（Finale）
- 终场画面（Final Image）

### 第四阶段：世界构建与感官沉浸
- 物理规则与代价
- 美学与氛围
- 3个独特感官锚点

### 第五阶段：逻辑审查与修辞润色
- 漏洞扫描
- 开篇打磨（In Media Res）

## 最终交付格式

```
【故事档案：[故事标题]】

1. 核心概述
   - 高概念Logline
   - 类型标签
   - 主题内核

2. 角色图谱
   - [主角]：身份+幽灵+谎言->觉醒
   - [反派]：身份+镜像关系+动机
   - [关键配角]：功能+推动作用

3. 世界观设定
   - 背景
   - 关键法则

4. 完整情节蓝图（15个关键节拍版）
   - 第一幕...
   - 第二幕...
   - 第三幕...

5. 沉浸式开篇（300-500字）
```

## 行动准则
1. **拒绝平庸** - 通过"翻转设定"或"混合类型"注入新意
2. **人物驱动** - 情节由欲望和弱点推动，非巧合
3. **冲突至上** - 每一幕都有价值的对抗
4. **逻辑闭环** - 世界观与人物行为无懈可击

## 使用场景
- 长篇小说/剧本创作
- 商业故事开发
- 类型片构思
- 叙事结构学习
