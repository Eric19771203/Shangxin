# Seedance 2.0 Director Fusion

> 从创意到视频的端到端 AI 视频生产系统

## 系统简介

**Seedance 2.0 Director Fusion** 是一个工业级 AI 视频生产系统，整合了：

- 🎬 **导演风格匹配** - 12位电影大师风格库
- 📝 **智能分镜设计** - Beat Board + Sequence Board 分层流程
- 🎯 **Seedance标准提示词** - 双版本输出（全能/首尾帧）
- 🔒 **一致性保障** - 全局参考池 + 尾帧锚定链

## 核心工作流程

```
输入 → 需求解析 → 导演匹配 → 分镜设计 → Seedance提示词 → 生产包
```

### Phase 1: 需求解析
- 提取：主题/情感/场景/人物
- 识别：类型/风格倾向
- 判定：复杂度等级

### Phase 2: 导演匹配
- 类型匹配 → 情感匹配 → 风格匹配
- 输出：1主导演 + 2备选 + 风格词库

### Phase 3: 分镜设计
- Beat Board（九宫格叙事总览）
- Sequence Board（四宫格镜头展开）
- 15秒模块化设计

### Phase 4: 提示词生成
- 按Seedance黄金公式组装
- 插入导演风格关键词
- 双版本输出（全能/首尾帧）

### Phase 5: 一致性保障
- 全局参考池配置
- 尾帧锚定链
- 批量生产参数

## 输出格式

每个项目输出包含：

1. **项目概览** - 名称、导演、时长、镜头数
2. **导演风格锁定** - 主导演、视觉风格、色彩基调
3. **Beat Board** - 九宫格叙事总览
4. **Sequence Board** - 四宫格分镜展开
5. **Seedance提示词（全能参考版）** - 多素材复杂场景
6. **Seedance提示词（首尾帧版）** - 一致性锁定链
7. **一致性保障配置** - 全局参考、尾帧锚定
8. **生产参数** - 模型、分辨率、生成策略

## Seedance黄金公式

```
@引用素材 → 主体/角色 → 场景环境 → 动作/行为 → 
运镜/镜头语言 → 风格/质感/光影 → 节奏/时长/音效 → 负面提示
```

## 一致性保障机制

### 1. 全局参考池
```yaml
全局参考池:
  角色A三视图: [正面, 侧面, 背面]
  角色B三视图: [正面, 侧面, 背面]
  主场景全景: 环境全貌图
  导演风格参考: 视觉风格样图
```

### 2. 尾帧锚定链
```
Module 1: 首帧@初始 → 生成 → 尾帧@M1_end
Module 2: 首帧@M1_end → 生成 → 尾帧@M2_end
Module 3: 首帧@M2_end → 生成 → 尾帧@M3_end
...
```

### 3. 音频先导
- 下一段音频提前0.5-1秒进入上一段结尾
- 利用听觉连贯性掩盖视觉微跳变

## 使用建议

### 提示词编写
- ✅ 推荐：缓慢、轻柔、连贯、自然、流畅
- ❌ 避免：剧烈、复杂、多人互动、大幅度扭曲

### 参数设置
- 参考权重：强一致性 0.8-0.9；动作幅度大 0.5-0.7
- 单次生成：建议4条择优
- 拥堵时：切换 Seedance 2.0 Fast

### 常见问题
| 问题 | 解决方案 |
|------|----------|
| 人物崩脸 | 减小动作幅度，使用@尾帧锁定 |
| 画风漂移 | 使用@全局画风锁定 |
| 过渡生硬 | 使用尾帧锚定或0.5秒叠化 |
