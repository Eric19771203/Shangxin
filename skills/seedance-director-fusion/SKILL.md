# Seedance 2.0 Director Fusion

> **版本**: V1.0 Fusion Edition
> **定位**: 工业化 AI 视频生产中枢
> **核心能力**: 导演风格 × 分镜设计 × Seedance 提示词 × 一致性保障

---

## 系统架构

```
用户输入 → 需求解析 → 导演匹配 → 分镜设计 → Seedance提示词 → 批量生成
                ↓           ↓           ↓              ↓
           [需求分析]  [风格锁定]  [Beat/Sequence]  [双版本输出]
```

## 工作流程

### Phase 1: 创意解析（Input → Concept）
```
用户输入
    ↓
[需求分析引擎]
    ├─ 提取：主题/情感/场景/人物
    ├─ 识别：类型/风格倾向
    └─ 判定：复杂度等级
    ↓
输出：创意简报（Creative Brief）
```

### Phase 2: 导演匹配（Concept → Director）
```
创意简报
    ↓
[导演匹配引擎]
    ├─ 类型匹配
    ├─ 情感匹配
    ├─ 视觉偏好匹配
    └─ 推荐1主+2备选
    ↓
输出：导演风格锁定 + 风格词库
```

**导演风格词库映射示例（Villeneuve）:**
```yaml
visual_keywords:
  - 宏大构图
  - 极简美学
  - 自然光运用
  - 航拍广角
  - 大气透视

camera_style:
  - 缓慢推镜
  - Dolly in
  - 广角镜头
  - 固定长镜头

color_palette:
  - 沙色调
  - 冷色调
  - 高对比度
  - 去饱和

seedance_prompt_template: |
  史诗级视觉，极简构图，{主体}在{场景}，
  自然光照射，大气透视，电影质感，8K，HDR
```

### Phase 3: 分镜设计（Director → Storyboard）
```
导演风格 + 创意简报
    ↓
[分镜设计引擎]
    ├─ 节拍拆解（Beat Breakdown）
    │   └─ 识别叙事锚点
    ├─ Beat Board（九宫格总览）
    │   └─ 9个关键画面
    └─ Sequence Board（四宫格展开）
        └─ 每个Beat拆4个镜头
    ↓
输出：完整分镜文档
```

**分镜结构标准：**
- **15秒模块化**：每个Beat = 1个15秒视频模块
- **时间分配**：
  - 0-3秒：钩子镜头（Hook）
  - 3-10秒：主体叙事（Body）
  - 10-15秒：收尾衔接（Transition）

### Phase 4: Seedance提示词生成（Storyboard → Prompt）
```
分镜 + 导演风格词
    ↓
[提示词生成引擎]
    ├─ 按黄金公式组装
    ├─ 插入导演风格关键词
    ├─ 添加一致性锁定
    └─ 双版本输出
    ↓
输出：可直用Seedance提示词
```

**Seedance黄金公式（强制遵守）：**
```
@引用素材 → 主体/角色 → 场景环境 → 动作/行为 → 
运镜/镜头语言 → 风格/质感/光影 → 节奏/时长/音效 → 负面提示
```

### Phase 5: 一致性保障（Prompt → Production）
```
提示词集合
    ↓
[一致性引擎]
    ├─ 全局参考池锁定
    ├─ 尾帧锚定链
    ├─ 音频先导配置
    └─ 批量生成参数
    ↓
输出：生产就绪包
```

## 使用方式

### 基础用法
```
用户：写一个未来战士在废墟中觉醒的15秒视频
系统：
  1. 识别类型→科幻史诗
  2. 匹配导演→Villeneuve
  3. 生成分镜
  4. 输出双版本Seedance提示词
```

### 进阶用法
```
用户：用王家卫风格，做一个都市夜晚邂逅的60秒短片，分4个模块
系统：
  1. 锁定导演→Wong Kar-wai
  2. 风格词→霓虹、抽帧、红绿对比
  3. 生成4个Beat（每Beat15秒）
  4. 每个Beat拆4个镜头
  5. 输出完整生产包
```

### 专业用法
```
用户：已有分镜，需要转化为Seedance提示词，导演指定诺兰
系统：
  1. 解析输入分镜
  2. 应用Nolan风格
  3. 转换为Seedance格式
  4. 输出双版本
```

## 一致性保障机制

### 1. 全局参考池
项目启动时建立，所有模块强制引用：
```yaml
全局参考池:
  角色A三视图: [正面, 侧面, 背面]
  角色B三视图: [正面, 侧面, 背面]
  主场景全景: 环境全貌图
  导演风格参考: 视觉风格样图
```

### 2. 尾帧锚定链
```
Module 1: 首帧@初始 → 生成 → 尾帧@M1_end
Module 2: 首帧@M1_end → 生成 → 尾帧@M2_end
Module 3: 首帧@M2_end → 生成 → 尾帧@M3_end
...
```

### 3. 音频先导策略
- 下一段音频提前0.5-1秒进入上一段结尾
- 利用听觉连贯性掩盖视觉微跳变

## 最佳实践

### 提示词编写技巧
- ✅ 推荐：缓慢、轻柔、连贯、自然、流畅
- ❌ 避免：剧烈、复杂、多人互动、大幅度扭曲
- ✅ 推荐：缓慢推镜、平稳跟拍、固定镜头
- ❌ 避免：极速甩镜、无规则晃动

### 参数设置
- 参考权重：强一致性 0.8-0.9；动作幅度大 0.5-0.7
- 单次生成：建议4条择优
- 拥堵时：切换 Seedance 2.0 Fast

### 常见问题
| 问题 | 解决方案 |
|------|----------|
| 人物崩脸 | 减小动作幅度，使用@尾帧锁定，增加负面提示 |
| 画风漂移 | 使用@全局画风锁定，检查风格词一致性 |
| 过渡生硬 | 使用尾帧锚定，或添加0.5秒叠化 |
